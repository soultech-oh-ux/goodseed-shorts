# 굿씨드 묵상숏츠 (Android) — 0.5.0 (최근 작품 삭제 · 무료 자료 출처 추가: NASA·명화·무료 음악)

굿씨드AI연구소. 묵상 글을 붙여넣으면 **낭독(폰 기본 음성 또는 내 목소리) + 자막 + 배경 + 음악**이 들어간 **1080x1920 세로 MP4** 를 만들어 갤러리에 저장하고 유튜브·카카오톡으로 공유하는 앱입니다.

- 설치 파일: `dist\goodseed-shorts-0.5.0.apk` + `dist\goodseed-shorts-0.5.0.apk.sha256`(서명됨 — 0.1.0~0.4.0 과 같은 키, 위에 덮어 업데이트 가능, arm64, 안드로이드 10 이상) + `.sha256`
- 변경 기록 `CHANGELOG.md`, 디자인 결정 근거 `DESIGN-0.2.0.md`(0.3.0·0.4.0 화면도 같은 디자인 틀)
- 소스: `android\` (Kotlin · Jetpack Compose · AndroidX Media3 Transformer 1.11.1)

## 사용법 (화면 7개)

1. **홈** — [새 묵상 영상 만들기], **영상 스타일 8종 가로 목록**(누르면 그 스타일로 바로 시작), 최근 작품(눌러서 보기 / [공유] / **[삭제]** — 확인 창에서 '갤러리 영상도 함께 지우기'는 체크해야만, 0.5.0), [업데이트 확인], [정보와 라이선스]. 새 버전이 있으면 맨 위에 안내 배너.
2. **글 붙여넣기** — 글을 붙여넣거나 쓰면 문장 단위로 자동 분할("N개 장면"). 한 문장 = 자막 한 장 = 낭독 한 구간. 자막 글자는 입력한 글에서만 만들어집니다.
3. **스타일 고르기** — 템플릿 8종(새벽 묵상·말씀 카드·감성 필름·미니멀 화이트·밤하늘·따뜻한 노을·성경 구절 강조·인용 명언) 카드를 누르면 적용. 제목·출처 입력(선택).
4. **목소리** — 맨 위에서 **[AI 목소리] / [내 목소리]** 선택.
   - AI 목소리: 폰에 설치된 한국어 음성 카드 목록, [들어보기], 속도 [느리게]/[보통].
   - 내 목소리 ① **문장마다 녹음하기(권장)**: 문장이 크게 표시 → [● 녹음] / [■ 멈춤] → [다시 녹음] [들어보기] [다음 문장] [이전 문장] [건너뛰기], 진행 n/N, 녹음 중 소리 크기 막대, 앞뒤 무음 자동 다듬기 + 소리 크기 맞춤. 마이크 권한을 거부하면 [설정 열기] 안내.
   - 내 목소리 ② **녹음 파일 올리기**: 폰의 녹음 1개(m4a·mp3·wav·aac 등) → 쉼 감지로 문장 경계 자동 추정(글자 수 비례 보정) → **자막 맞추기** 화면(문장별 [들어보기], 시작 시간 [◀ 0.5초][0.5초 ▶] · [◀ 0.1초][0.1초 ▶]) → [이대로 확정].
   - 일부 문장만 녹음했으면 [다음]에서 "나머지를 AI 목소리로 채울까요?" 확인. 녹음은 앱 내부 저장소(`files/recordings/<작품>/`)에만 저장, 외부 전송 없음.
5. **배경·음악** — 내 사진·영상 여러 장 선택(번호=순서) / [파일에서 가져오기](굿씨드다운으로 받은 영상) / **[무료 사진·영상 찾기](0.4.0, 키 필요 없음)** / 음악은 폰 음원 선택, 낭독 구간에서 자동으로 작아짐 / 맨 아래 "그 밖의 선택 기능"에 Pexels 영상 검색(**API 키를 직접 넣어야만 켜짐**, 'Provided by Pexels' 표기). "권리를 확인한 자료만 쓰세요" 안내.
   - **무료 사진·영상 찾기**: [사진]/[영상] → **출처 탭(전체·위키미디어·Openverse·NASA·명화, 0.5.0)** → 주제 버튼 16개(명화 탭은 목자·십자가·기도·천사·성경·풍경)(일출·노을·바다·하늘·구름·숲·꽃·별·빛·십자가·교회·산·강·비·눈·들판) 또는 직접 입력(한글은 사전으로 영어로 바꿔 찾음) → 결과 격자(제목·이용 조건 표시) → 누르면 미리보기(작가·이용 조건·크기) → [이 자료 넣기](진행률·[받기 취소]). 위키미디어 공용(사진·영상) + Openverse(사진 보조) + **NASA(사진·영상, 공개 도메인, 로고·휘장 자료는 거름)** + **메트로폴리탄 미술관 명화(공개 도메인)**; 출처 하나가 실패하면 조용히 건너뜀. 표시하는 이용 조건: CC0 · 공개 도메인 · CC BY 만. 크기 상한 영상 100MB·사진 20MB.
   - **무료 음악 찾기(0.5.0)**: [배경과 음악] → [무료 음악 찾기] → 분위기 버튼(잔잔한 피아노·기타·현악·자연 소리·찬양 분위기·명상)/직접 입력 → 곡 카드(제목·작가·이용 조건·길이) → [미리듣기] / [넣기](진행률·취소). Openverse 음악, 상한 20MB, 출처 자동 기록.
   - **출처 표기**: 쓰인 무료 자료가 있으면 "사진·영상 출처 표기"에서 [영상 끝에 넣기]/[넣지 않기](기본 넣기). 저장이 끝난 화면의 [출처 문구 복사 (유튜브 설명란용)] 버튼.
6. **미리보기·수정** — 9:16 미리보기(템플릿 적용), **스타일 바꾸기 줄**, 문장 카드를 누르면 글자·배경 사진·자막 크기(4단계) 수정, 자막 글꼴 Pretendard / 고운바탕. 타임라인 없음.
7. **저장·공유** — [영상 만들기 시작] → 진행률 → 갤러리(Movies/굿씨드묵상숏츠) 저장 → [유튜브로 공유] [카카오톡으로 공유] [다른 앱으로 공유].

## 만든 방식(요약)

- 문장 분할 `SentenceSplitter`, 자막 줄바꿈 `SubtitleWrapper`(금칙 처리·균형 줄바꿈, 직접 구현), 덕킹 곡선 `DuckingCurve`, 시간표 `Timing`, 낭독 wav 앞뒤 무음 `WavPad` — 모두 순수 Kotlin 이라 JVM 에서 시험됩니다.
- 합성: `Composition` 3줄 — 영상 줄(장면 길이만큼 배경, 영상은 자르거나 반복, 1080x1920 으로 채워 자름) / 낭독 줄(장면마다 wav 한 개) / 음악 줄(길이만큼 이어 붙이고 조각마다 `DuckingAudioProcessor`). 자막은 합성 전체에 거는 시간별 `TextOverlay`(`SubtitleOverlay`).
- 글꼴: Pretendard Bold, 고운바탕 Bold/Regular(SIL OFL 1.1) — `assets/licenses/` 에 전문 포함.
- 릴리스 파일 이름 고정: `python tools\make_release_files.py <서명된 apk>` → `dist\goodseed-shorts-X.Y.Z.apk` + `.apk.sha256`('해시  파일명' 한 줄). `--check` 로 규칙 검사. 시험 `ReleaseFilesTest`.
- 비밀 없음: Pexels 키는 사용자가 입력(앱 내부 저장), 코드에 키 없음. 유료 API 호출 없음. 위키미디어·Openverse 는 키가 필요 없고, 요청에는 앱 이름·버전·릴리스 페이지 주소가 든 User-Agent 만 보냅니다(개인 연락처 없음).

## 한계 (알고 쓰세요)

- (0.3.0) 내 목소리: 문장 경계 자동 추정은 쉼이 또렷할수록 잘 맞고, 쉼 없이 이어 읽은 파일은 글자 수 비례로 어림잡기 때문에 [자막 맞추기]에서 고쳐야 할 수 있습니다. 올린 파일은 최대 10분, 전체 소리 크기를 한 번에 맞춥니다. AI 목소리로 채운 문장은 소리 크기를 자동으로 맞추지 않습니다. 녹음은 작품을 새로 시작한 뒤 7일이 지나면 정리됩니다. 앱을 끄면 편집 상태(어느 문장이 녹음됐는지)가 사라지므로 녹음과 영상 만들기는 한 번에 끝내는 것을 권합니다.
- 장면 전환 효과·타임라인 편집 없음. 확대/이동 효과는 템플릿이 정한 사진 배경에만 걸립니다(영상 배경 제외).
- 앱 안 업데이트는 GitHub 에 올라온 릴리스(시험판 포함)를 따릅니다. 처음 한 번은 '출처를 알 수 없는 앱' 허용이 필요하고, 설치 화면에서 사용자가 직접 [업데이트]를 눌러야 합니다.
- 만드는 동안 앱을 켜 둬야 합니다(백그라운드 합성 서비스 없음). 화면은 꺼지지 않게 설정됩니다.
- 작품은 앱을 끄면 편집 상태가 사라집니다(저장된 mp4 와 '최근 작품' 목록만 남음).
- 인터넷이 필요한 음성(네트워크 음성)은 오프라인에서 낭독을 만들지 못합니다(목록에 표시).
- 영상 인코더가 1080x1920 을 지원하지 않는 기기에서는 결과 크기를 검사해 오류로 알립니다.
- 사진·영상 권한은 시스템 사진 선택기/파일 선택기를 쓰므로 별도 저장소 권한이 없습니다. 세션이 끝나면 선택 권한이 사라질 수 있어, 만들기는 한 번에 끝내는 것을 권합니다.
- 빌드 환경: Media3 1.11 이 요구해 **compileSdk 36 · Kotlin 2.2.10** 입니다(AGP 8.7.3 는 경고 억제 `android.suppressUnsupportedCompileSdk=36`). 안드로이드 SDK 플랫폼 36 설치 필요.
- 서명 키는 `android\keystore\`(깃 제외)에 새로 만들었습니다. **잃어버리면 같은 앱으로 업데이트 배포가 불가능**하니 백업이 필요합니다(오너 결정).

19. **출처 표기**: 무료 자료를 쓴 영상을 저장 → 마지막 장면부터 아래쪽에 출처 글자("자료: 작가(CC BY 4.0) · … · 위키미디어 공용")가 읽기 좋게 나오는가(글자 크기·자막과 겹치지 않는가, 최대 4줄), [배경과 음악]에서 [넣지 않기]로 바꾸면 안 나오는가.
20. **[출처 문구 복사]**: 저장이 끝난 화면에서 누르고 유튜브 설명란(또는 메모)에 붙여 넣는다 → 제목·작가·이용 조건·원본 링크가 자료마다 들어 있는가.
21. **Openverse·Pexels**: 사진 검색 결과에 Openverse 사진이 섞여 나오는가(느리거나 안 나와도 오류 문구가 없어야 정상). Pexels 키가 있으면 [배경과 음악] 맨 아래 "그 밖의 선택 기능"에서 검색·추가가 되는가(이전 버전에서 추가가 안 됐다면 이번에 고친 부분이다), 추가한 Pexels 영상이 출처 문구에 들어가는가.
22. **최근 작품 삭제(0.5.0)**: 작품을 2~3개 만들어 둔 뒤 홈의 최근 작품 카드에 [삭제]가 보이고 누르기 쉬운가 → 누르면 '이 작품을 지울까요?' 창, 체크가 기본으로 꺼져 있는가 → 체크 없이 [지우기]: 목록에서만 빠지고 갤러리(Movies/굿씨드묵상숏츠)의 영상은 그대로인가, '지웠습니다.' 알림이 뜨다 사라지는가 → [취소]는 아무것도 안 지우는가.
23. **갤러리 영상도 함께 지우기**: 다른 작품에서 체크하고 [지우기] → 갤러리 영상이 사라지는가, 폰이 한 번 더 확인 창을 띄우면(허용/거부 둘 다 해 본다) 허용 시 '지웠습니다.', 거부 시 '갤러리의 영상은 그대로 두었습니다…' 가 뜨는가. 갤러리에서 영상을 먼저 지워 둔 작품도 정상적으로 지워지는가. 앱을 껐다 켜도 지운 작품이 다시 안 나타나는가.
24. **출처 탭(NASA·명화)**: [무료 사진·영상 찾기]에서 [전체]/[NASA]/[명화] 탭을 눌러 본다. 전체 탭에 여러 출처가 섞여 나오는가(느린 출처는 조금 뒤 추가), 출처 하나가 안 떠도 오류 문구 없이 나머지가 나오는가, 영상 모드에 명화·Openverse 탭이 없는가, NASA 탭에 'NASA 가 보증하는 것처럼 보이게 쓰지 마세요' 안내가 보이는가.
25. **NASA 사진·영상 넣기**: NASA 사진(예: 일출·우주)을 넣어 영상을 만들어 본다. NASA 영상은 받는 데 오래 걸릴 수 있다(약 65MB) — 진행률·[받기 취소]가 되는가, 받은 mp4 가 합성에 들어가 9:16 으로 잘 잘리는가. NASA 로고·휘장 그림이 결과에 나오지 않는가.
26. **명화 넣기**: [명화] 탭에서 목자·십자가·기도 등을 눌러 결과가 나오는가(몇 초), 미리보기에 작가·'공개 도메인' 이 보이는가, 큰 그림이 잘 받아지고 영상 배경으로 잘 보이는가.
27. **무료 음악 찾기**: [배경과 음악] → [무료 음악 찾기] → 분위기 버튼(잔잔한 피아노 등) → 곡 목록(제목·작가·CC BY·길이)이 뜨는가(Openverse 가 느리거나 안 되면 오류 안내) → [미리듣기]로 소리가 나는가(다시 누르면 멈추는가, 다른 곡을 누르면 앞 곡이 멈추는가, 화면을 나가면 멈추는가) → [넣기]로 받아지는가(진행률·[받기 취소]).
28. **음악이 들어간 영상**: 무료 음악을 넣고 영상을 만든다 → 곡이 영상 전체에 깔리는가(곡이 짧으면 반복), 낭독 때 음악이 작아지는가, 재생이 끊기지 않는가.
29. **출처 표기**: 새 출처(NASA·명화·음악)를 쓴 영상에서 끝 글자에 'NASA / …(공개 도메인)', '… 메트로폴리탄 미술관' 등이 읽기 좋게 나오는가, 저장 후 [출처 문구 복사]를 붙여 넣으면 자료·음악별 줄과 끝의 'Credit: NASA' / 'The Metropolitan Museum of Art, Public Domain (Open Access)' 줄이 있는가.
30. 문제가 있으면: 폰 모델·안드로이드 버전, 어느 단계, 화면에 뜬 오류 문구를 알려 주세요.
