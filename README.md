# 굿씨드 묵상숏츠 (Android) — 0.2.0 (디자인 리뉴얼 + 영상 템플릿 8종 + 앱 안 업데이트)

굿씨드AI연구소. 묵상 글을 붙여넣으면 **낭독(폰 기본 음성) + 자막 + 배경 + 음악**이 들어간 **1080x1920 세로 MP4** 를 만들어 갤러리에 저장하고 유튜브·카카오톡으로 공유하는 앱입니다.

- 설치 파일: `dist\goodseed-shorts-0.2.0.apk` (서명됨 — 0.1.0 과 같은 키, 위에 덮어 업데이트 가능, arm64, 안드로이드 10 이상) + `.sha256`
- 변경 기록 `CHANGELOG.md`, 디자인 결정 근거 `DESIGN-0.2.0.md`
- 소스: `android\` (Kotlin · Jetpack Compose · AndroidX Media3 Transformer 1.11.1)

## 사용법 (화면 7개)

1. **홈** — [새 묵상 영상 만들기], **영상 스타일 8종 가로 목록**(누르면 그 스타일로 바로 시작), 최근 작품(눌러서 보기 / [공유]), [업데이트 확인], [정보와 라이선스]. 새 버전이 있으면 맨 위에 안내 배너.
2. **글 붙여넣기** — 글을 붙여넣거나 쓰면 문장 단위로 자동 분할("N개 장면"). 한 문장 = 자막 한 장 = 낭독 한 구간. 자막 글자는 입력한 글에서만 만들어집니다.
3. **스타일 고르기** — 템플릿 8종(새벽 묵상·말씀 카드·감성 필름·미니멀 화이트·밤하늘·따뜻한 노을·성경 구절 강조·인용 명언) 카드를 누르면 적용. 제목·출처 입력(선택).
4. **목소리** — 폰에 설치된 한국어 음성 카드 목록, [들어보기], 속도 [느리게]/[보통].
5. **배경·음악** — 내 사진·영상 여러 장 선택(번호=순서) / [파일에서 가져오기](굿씨드다운으로 받은 영상) / Pexels 영상 검색(**API 키를 직접 넣어야만 켜짐**, 'Provided by Pexels' 표기) / 음악은 폰 음원 선택, 낭독 구간에서 자동으로 작아짐. "권리를 확인한 자료만 쓰세요" 안내.
6. **미리보기·수정** — 9:16 미리보기(템플릿 적용), **스타일 바꾸기 줄**, 문장 카드를 누르면 글자·배경 사진·자막 크기(4단계) 수정, 자막 글꼴 Pretendard / 고운바탕. 타임라인 없음.
7. **저장·공유** — [영상 만들기 시작] → 진행률 → 갤러리(Movies/굿씨드묵상숏츠) 저장 → [유튜브로 공유] [카카오톡으로 공유] [다른 앱으로 공유].

## 만든 방식(요약)

- 문장 분할 `SentenceSplitter`, 자막 줄바꿈 `SubtitleWrapper`(금칙 처리·균형 줄바꿈, 직접 구현), 덕킹 곡선 `DuckingCurve`, 시간표 `Timing`, 낭독 wav 앞뒤 무음 `WavPad` — 모두 순수 Kotlin 이라 JVM 에서 시험됩니다.
- 합성: `Composition` 3줄 — 영상 줄(장면 길이만큼 배경, 영상은 자르거나 반복, 1080x1920 으로 채워 자름) / 낭독 줄(장면마다 wav 한 개) / 음악 줄(길이만큼 이어 붙이고 조각마다 `DuckingAudioProcessor`). 자막은 합성 전체에 거는 시간별 `TextOverlay`(`SubtitleOverlay`).
- 글꼴: Pretendard Bold, 고운바탕 Bold/Regular(SIL OFL 1.1) — `assets/licenses/` 에 전문 포함.
- 비밀 없음: Pexels 키는 사용자가 입력(앱 내부 저장), 코드에 키 없음. 유료 API 호출 없음.

## 한계 (알고 쓰세요)

- 장면 전환 효과·타임라인 편집 없음. 확대/이동 효과는 템플릿이 정한 사진 배경에만 걸립니다(영상 배경 제외).
- 앱 안 업데이트는 GitHub 에 올라온 릴리스(시험판 포함)를 따릅니다. 처음 한 번은 '출처를 알 수 없는 앱' 허용이 필요하고, 설치 화면에서 사용자가 직접 [업데이트]를 눌러야 합니다.
- 만드는 동안 앱을 켜 둬야 합니다(백그라운드 합성 서비스 없음). 화면은 꺼지지 않게 설정됩니다.
- 작품은 앱을 끄면 편집 상태가 사라집니다(저장된 mp4 와 '최근 작품' 목록만 남음).
- 인터넷이 필요한 음성(네트워크 음성)은 오프라인에서 낭독을 만들지 못합니다(목록에 표시).
- 영상 인코더가 1080x1920 을 지원하지 않는 기기에서는 결과 크기를 검사해 오류로 알립니다.
- 사진·영상 권한은 시스템 사진 선택기/파일 선택기를 쓰므로 별도 저장소 권한이 없습니다. 세션이 끝나면 선택 권한이 사라질 수 있어, 만들기는 한 번에 끝내는 것을 권합니다.
- 빌드 환경: Media3 1.11 이 요구해 **compileSdk 36 · Kotlin 2.2.10** 입니다(AGP 8.7.3 는 경고 억제 `android.suppressUnsupportedCompileSdk=36`). 안드로이드 SDK 플랫폼 36 설치 필요.
- 서명 키는 `android\keystore\`(깃 제외)에 새로 만들었습니다. **잃어버리면 같은 앱으로 업데이트 배포가 불가능**하니 백업이 필요합니다(오너 결정).

## 오너 폰 시험 체크리스트

1. 0.1.0 이 설치돼 있으면 그 위에 0.2.0 APK 를 설치(`dist\goodseed-shorts-0.2.0.apk`, 출처 불명 앱 허용) → 업데이트로 설치되는가, 첫 실행에 '새 버전(0.2.0)으로 업데이트되었습니다' 안내가 한 번 뜨는가. 홈이 새 디자인으로 열리는가.
2. 글 붙여넣기: 시편 23편 같은 글 → 문장이 맞게 나뉘는가, 장면 수 표시.
3. 목소리: 한국어 음성 목록이 뜨는가, [들어보기] 소리가 나는가, [느리게]/[보통] 차이.
4. 배경: 사진 3장+영상 1개 선택 → 번호 순서, 영상 가져오기, (Pexels 키가 있으면) 검색·추가. 음악 1곡 선택.
5. 미리보기: 자막이 읽기 좋은가(4단계 크기, 두 글꼴), 장면 수정(글자 고치기)이 반영되는가.
6. 저장: 3~5문장으로 [영상 만들기 시작] → 진행률이 올라가는가, 끝나면 갤러리 `Movies/굿씨드묵상숏츠` 에 생기는가.
6-1. 스타일 8종을 바꿔 가며 같은 글로 만들어 본다: 자막 위치·글자색·그림자·외곽선이 미리보기와 같은가, 사진 배경에서 천천히 확대/이동하는가(끊김·가장자리 빈틈 없는가), 제목·출처가 위쪽에 나오고 끝 화면이 붙는가(말씀 카드·미니멀·성경 구절 강조·인용 명언), 끝 화면 동안 소리가 어색하지 않은가.
7. 결과 영상: 1080x1920 세로인가, 자막이 낭독과 맞는가, 낭독 때 음악이 작아지고 끝나면 커지는가, 영상 배경이 장면마다 맞게 바뀌는가, 소리가 끊기거나 밀리지 않는가.
8. 공유: [유튜브로 공유] [카카오톡으로 공유] 가 열리는가(앱이 없으면 일반 공유창).
9. 새 버전 안내(master 가 새 릴리스를 올린 뒤): 홈 위 배너가 뜨는가, [업데이트 방법] 창, [업데이트]→진행률→설치 화면이 열리는가, [나중에]를 누르면 사라지고 다음 날 다시 뜨는가, 인터넷을 끄면 아무 표시 없이 넘어가는가.
10. 문제가 있으면: 폰 모델·안드로이드 버전, 어느 단계, 화면에 뜬 오류 문구를 알려 주세요.

## 개발 메모

- 빌드: `set JAVA_HOME=...\jdk17` 후 `android\gradlew.bat :app:testDebugUnitTest :app:assembleRelease`. 바탕화면 폴더에서 빌드 폴더가 잠기면 환경변수 `GS_BUILD_ROOT` 로 산출물 위치를 옮길 수 있습니다.
- `android\keystore.properties`(깃 제외)에서 서명 정보를 읽습니다.
- GitHub 원격 생성·push·배포는 하지 않았습니다(master 담당).
